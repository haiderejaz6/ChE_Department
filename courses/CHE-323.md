# CHE-323: Instrumentation and Process Control

| | |
|---|---|
| **Credit Hours** | 3-1 |
| **Prerequisites** | None |

## Course Objectives

- To familiarize students with the basic concepts of process control and instrumentation required for controlling chemical processes.
- To cover various control strategies, controlling equipment behaviors, and their response analysis.

## Course Contents

1. Incentives for process control.
2. Principles of measurement of temperature, pressure, level, flow, and concentration. Description of sensors for these process variables; characteristics and calibration of sensors; transmitters and transmission lines.
3. Laplace transform of differential equations and characterization of systems.
4. Transfer functions and block diagrams.
5. Dynamic behavior of first- and second-order systems.
6. Feedback control; types of feedback controllers.
7. Control valves: fail-safe mode, valve characteristics, and valve sizing.
8. Dynamic behavior of feedback-controlled processes: closed-loop response, servo and regulator problems.
9. Stability analysis of feedback control systems.
10. Tuning of feedback controllers.
11. Multi-loop control: cascade control, ratio control, split-range control, feed-forward control.
12. Safety instrumented systems: alarm, trip, and interlock systems.
13. P&ID diagrams.
14. Process control in the Industry 4.0 era.
15. Overview of AI applications in process control.
16. Simulink-based design and analysis of control loops for temperature, pressure, and flow rate of process streams/equipment.

## Course Outcomes

After completing this course, students must possess:

- Basic understanding of instrumentation, their principles of operation, advantages, and disadvantages.
- Essential understanding of various instruments used and applied in the process industry for process control.
- Complete knowledge of control systems, their characteristics, and components.
- Recognition and identification of various process diagrams and symbols used in IPC.
- Knowledge of different types of controllers, their application in industries, advantages, and disadvantages.
- Basic design concepts of different controllers.
- Understanding of requirements for a successful installation, instrument checkout, and controller tuning.

## List of Practicals

1. Calibrate the automatic flow sensor with a rotameter in the flow control unit and perform its line tracing.
2. Calibrate the automatic temperature sensor with a thermometer in the temperature control unit and perform its line tracing.
3. Calibrate the automatic level sensor with manual scale reading in the level control unit and perform its line tracing.
4. Calibrate the automatic pressure sensor with a manometer in the pressure control unit and perform its line tracing.
5. Implement the feedback control loop in ON/OFF mode in the flow control unit to achieve the required set point using different values of the tolerance band.
6. Implement the feedback control loop in PID mode in the flow control unit to achieve the required set point using different values of the proportional band Kc.
7. Implement the feedback control loop in ON/OFF mode in the level control unit to achieve the required set point using different values of the tolerance band, and analyze the graphical variation of level with respect to time.
8. Implement the feedback control loop in PID mode in the level control unit to achieve the required set point using different values of the proportional band Kc, and analyze the graphical variation of level with respect to time.
9. Implement the PID mode control loop in the pressure control unit for achieving different set points; analyze the behavior of the PID controller in case of an external disturbance.
10. Implement the PID mode control loop in the pressure control unit for achieving the required set point using different values of the proportional band Kc and conclude graphically.
11. Implement feedback control PI mode in the flow control unit for achieving the required set point using the Ziegler-Nichols control loop method.
12. Implement feedback control PID mode in the flow control unit for achieving the required set point using the Ziegler-Nichols control loop method.
