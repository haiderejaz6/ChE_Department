| | |
|---|---|

## Course Description

Successful completion of the course should develop the ability to select an appropriate and efficient method for solving linear systems of equations, and the handling of eigenvalue problems, which are extensively studied — for example, in resonance and vibration theory. The course also builds an understanding of ordinary differential equations, a strong tool for mathematical modeling, and an understanding of Laplace transforms with applications in various engineering/technological concepts.
