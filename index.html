How concepts are extracted

Each course's CLO descriptions are processed by excel_to_json.py using one of two strategies — selectable via the --mode flag:

Rule-based --mode rule
A curated library of ~90 regex patterns maps CLO text to short canonical concepts (1–2 words). Fast, deterministic, and works offline — used by GitHub Actions CI so the site can auto-update without an LLM server.
LLM-assisted --mode llm / both
All CLOs for a course are sent in a single Ollama prompt (local LLaMA 3 / Mistral / Phi-3). The model extracts 8–14 generic 1–2 word concepts per course, then a second pass normalises synonyms across the whole programme vocabulary — maximising cross-course overlap detection.

Short, generic labels (e.g. kinetics rather than reaction kinetics fundamentals) are deliberately preferred so that concepts shared across courses surface clearly in all three views below. Run python scripts/excel_to_json.py --mode both locally after updating the Excel file for the richest results.
